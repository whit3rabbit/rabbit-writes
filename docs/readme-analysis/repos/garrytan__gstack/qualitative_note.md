# garrytan/gstack — qualitative note

This README opens with a personal, almost blog-post-style narrative — a Karpathy quote, the author's YC/Palantir/Posterous credentials, and self-reported productivity stats ("~810× my 2013 pace") — before ever describing installation, which is a distinctive founder-voice approach that trades neutral tone for credibility-by-story. Structurally it's dense but well-organized: a numbered "Quick start," copy-paste install blocks meant to be pasted directly into an AI agent (not run by the human), and a large "sprint" skill-reference table mapping each slash command to a named role ("CEO," "Staff Engineer," "QA Lead") and one-line description, which reinforces the "virtual engineering team" metaphor throughout. A strong formatting technique is the "See it work" section — a mocked terminal transcript showing a realistic back-and-forth (`/office-hours` → `/plan-ceo-review` → `/ship`) that demonstrates the tool's behavior concretely instead of just asserting it. The doc also models transparency by linking to a dedicated methodology doc for a controversial claim ("Full methodology, caveats, and reproduction script") rather than just asserting the number. On the downside, the README is extremely long and mixes marketing narrative with deep reference material (uninstall scripts, telemetry policy, troubleshooting) in one continuous scroll, which works as an exhaustive single-source-of-truth but is not optimized for a first-time skimmer.
