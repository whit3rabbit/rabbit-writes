# Layout: cheatsheets

**Index file:** README.md
**Link syntax:** markdown
**Frontmatter keys:** (none)
**Note kinds:** concept
**Spine notes:** (none)
**Folders:** (flat)

The default layout, and the one this skill shipped with: a flat folder of
per-concept docs, one `*.md` per concept, with a `README.md` index beside
them. Every doc follows its book type's template and nothing else: no
frontmatter block, no spine notes, no subfolders.

The index is a Doc/Source/Kind table, one row per doc, where every row names
a real file in the folder and every doc appears exactly once. See also links
are plain markdown links naming sibling files by filename.
