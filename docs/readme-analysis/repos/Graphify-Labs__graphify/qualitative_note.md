# Graphify-Labs/graphify — qualitative note

Graphify's README is huge (872 lines) but structures itself around a strict "30 seconds to first result" promise near the top, showing the exact three-line install/run sequence and the exact three output files before diving into anything else — a strong best-practice pattern for tools with a CLI quickstart. It backs claims with a real, reproducible terminal transcript (`graphify explain "APIRouter"` / `graphify path "FastAPI" "ModelField"`) rather than a staged screenshot, and a benchmarks table with named baselines (mem0, supermemory) and a stated judge-agreement statistic, which is unusually rigorous for a README. The tone throughout is plain and technical with almost no marketing adjectives, favoring tables over prose (install matrix, extras matrix, env-var reference, troubleshooting entries) — appropriate for a dev-tool audience but it makes the doc read more like a manual than a pitch, and the sheer volume of platform-specific install variants (20+ agent integrations) pushes the actually-persuasive material far down the page. The troubleshooting section is notably good practice: each entry states the exact error string as a heading before explaining the fix, so users can `Ctrl+F` their symptom directly.

**Quotes:**
- "**Not a vector index.** No embeddings, no vector store: a real graph you traverse. Ask a question, trace the path between two things, or explain one concept."
- "Every edge carries a **confidence tag** (`EXTRACTED` = explicit in the source, `INFERRED` = derived by resolution), so you can tell what was read directly from what was inferred."
